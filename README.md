# 水泳タイマー (ラップ一括計測) / Swim Lap Timer

複数の組・選手が時差スタート（ウェーブスタート / サイクル練習）を行う水泳のトレーニングやタイム計測において、ボタン1つのタッチ操作で自動的に「本数」「組」「着順」およびハンデを控除した**純粋な計算タイム（泳ぎタイム）**を自動記録・算出し、CSVでダウンロードできるWebアプリケーションです。

---

## 🌟 特徴・主な機能

1. **柔軟なグループ＆ハンデ設定**
   - **レーン数 (1組の人数):** 1〜10人
   - **総人数 (全選手数):** 1〜100人
   - **スタート間隔:** 3秒 / 5秒 / 10秒 / 15秒 / 20秒 から選択
   - **サイクル時間:** 60秒など、任意のサイクル時間を秒単位で設定可能

2. **直感的な1ボタンタップ計測 (ラップ機能)**
   - 選手がゴール・タッチした瞬間に「ラップ（タッチ）」ボタンを押すだけ。
   - 通過順（全体の計測順）から、「何本目（サイクル）」「何組目」「組内着順」を自動判別します。

3. **自動タイム計算（ハンデ控除）**
   - 全体経過時間（実計測時間）から、該当する組のウェーブスタート遅延およびサイクル遅延時間を自動で差し引き、**実際の泳ぎタイム（計算タイム）**を正確に記録します。

4. **リアルタイムな状態表示 & 履歴確認**
   - 現在何本目か、次に何組目が帰ってくるかの予想ステータス表示。
   - 最新の計測記録がテーブル最上部にリアルタイム追加されます。

5. **CSVエクスポート対応**
   - 計測完了後、「CSV出力」ボタンをクリックすることで、UTF-8形式（BOMなし）で記録データをダウンロード可能です。

---

## 🚀 使い方

1. **設定を行う**
   - `1組の人数` `総人数` `スタート間隔` `サイクル時間` を練習内容に合わせて設定します。

2. **計測を開始する**
   - 最初の組がスタートするタイミングで「スタート」ボタンを押します。

3. **ラップ（タッチ）を記録する**
   - 選手が泳ぎ終わる（タッチする）ごとに「ラップ（タッチ）」ボタンを押します。
   - 内部で組や本数が自動カウントアップされます。

4. **データを保存する**
   - 計測終了後、「リセット」を押してタイマーを停止させた後、「CSV出力」ボタンを押してデータ（`swim_records_YYYY-MM-DD.csv`）を保存します。

## 💻 技術構成

- **フロントエンド:** HTML5 / CSS3 / JavaScript (Vanilla JS)
- **外部依存ライブラリ:** なし（単一のHTMLファイルで動作）
- **動作環境:** モダンブラウザ（Chrome, Safari, Edge, Firefox 等 / スマホ・タブレット・PC対応）

## 📄 出力データ形式 (CSV)

| 列名 | 説明 | 例 |
| :--- | :--- | :--- |
| **番号** | 通過順番号 | 1 |
| **本数** | 何セット目（サイクル）か | 1本目 |
| **組** | 何組目か | 1組目 |
| **組内着順** | 組の中での着順 | 1着 |
| **計算タイム** | スタート遅延を引いた実際の泳ぎタイム | 00:35.2 |
| **実計測時間** | タイマースタートからの総経過時間 | 00:35.2 |
